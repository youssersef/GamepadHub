# 🎮 GamepadHub

**One app for every controller on Windows.** **برنامج واحد لكل الدراعات على الويندوز.**

PS4 · PS5 · Xbox · Generic / Twin USB · Bluetooth &amp; USB

---

## ✨ Why GamepadHub?

Some games only work with DS4Windows, others only with x360ce — and running both breaks everything. GamepadHub replaces both with **one app**, so every controller just works, in every game, without conflicts.

## 🚀 Features

- **3 modes per controller** — `PS` (virtual DualShock 4), `Xbox` (virtual Xbox 360) or `Raw` (the real controller, gyro &amp; touchpad included).
- **Per-game profiles** — change a mode while a game is open and GamepadHub remembers it for that game.
- **No double controllers** — the real controller is hidden from games automatically.
- **Bluetooth battery %**, rumble, and full **touchpad** support (even on many third-party PS4 pads).
- **Light bar color wheel** — each controller keeps its own color.
- **Live button tester** — sticks, triggers, touchpad and rumble, right inside the app.
- **Desktop mode** — use your controller as a mouse &amp; keyboard when no game is running.
- **Any controller** — built-in database of thousands of pads + a step-by-step mapper for unknown ones.
- **Themes** — 9 built-in themes and a full **theme editor** (colors, backgrounds, fonts) with import/export.
- **Arabic &amp; English** interface.
- **Auto-updates** from GitHub, starts with Windows, lives next to the clock.

## 🕹️ Controller shortcuts


| Combo                         | Action                                |
| ----------------------------- | ------------------------------------- |
| `Share + Options` (hold 1.5s) | Switch **PS ⇄ Xbox**                  |
| `Share + Options` (hold 7s)   | **Alt + F4** (close the game)         |
| `Share + Options + PS`        | Turn the Bluetooth controller **off** |
| `Options` / `Share` (desktop) | Left / right click                    |
| D-pad (desktop)               | Arrow keys                            |
| Touchpad (desktop)            | Mouse                                 |


## 📥 Install

1. Download **GamepadHub.exe** from [Releases](../../releases/latest).
2. Run it — the first launch installs the needed drivers (**ViGEmBus** &amp; **HidHide**) and asks for **one restart**.
3. Plug in or pair your controller. That's it.

> **Windows SmartScreen** may warn you because the app isn't code-signed yet. Click **More info → Run anyway**.

**Requirements:** Windows 10 / 11 (64-bit).
